# Expense Tracker

A simple C++ command-line application for tracking expenses.

## Features

- Add expenses
- View recorded expenses
- Store expense data in a file
- Calculate expense information
- Simple command-line interface

## Technologies

- C++
- Vectors
- Strings
- File I/O
- Git & GitHub

## How to Run

Compile:

```bash
g++ main.cpp -o ExpenseTracker
